# LibrosAppKotlin V1

Aplicación Android desarrollada en Kotlin utilizando Firebase.

## Funcionalidades
- Registro/Login
- Login con Google
- Roles administrador y cliente
- Gestión de libros PDF
- Lectura de libros
- Descarga de PDFs
- Categorías
- Buscador
- Favoritos
- Comentarios

## Tecnologías
- Kotlin
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage
- Glide
- Material Design

- Mejora visual UI/UX
